# Archivo de prueba

Este es un archivo de prueba para probar el funcionamiento de Git.

## Cambios en el archivo

1. Abre la terminal.
2. Escribe el comando `git commit --amend`. Para poder cambiar el mensaje del commit.
3. Escribe el mensaje del commit.

Otra opción es usar el comando `git commit --amend --no-edit` en la terminal. Sirve para agregar cambios de archivos sin editar el mensaje del commit.

## Push

Para push, sigue estos pasos:

1. Abre la terminal.
2. Escribe el comando `git push`.

Otra opción es usar el comando `git push -f` y el nombre de la rama en la que deseas hacer el push. Sirve para sobrescribir la rama remota con la rama local, solo dejandose ver el cambios 'invisible' en la actividad del repositorio.
