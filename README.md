# Proyecto GitHub

## Qué es GitHub?

GitHub es un sistema de control de versiones distribuido que permite a los desarrolladores colaborar en proyectos de software. Además de ser una plataforma donde almacenar proyectos y sirve de comunicación entre desarrolladores para realizar diversas tareas.

## Rama principal

La rama principal es la rama en la que se realizan los cambios más importantes en el proyecto. Sirviendo como punto de partida para las otras ramas.

## Ramas secundarias

Las ramas secundarias son ramas que se crean para realizar tareas específicas en el proyecto. Estas ramas se utilizan para dividir el trabajo en diferentes partes del proyecto y mantener el control de versiones separado.
